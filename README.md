## 🚀 Что умеет этот бот

### 1. 🎮 Мониторинг Steam раздач
Основная фича бота. Каждый день в **12:00 по МСК** бот автоматически проверяет RSS-ленту [GamerPower](https://www.gamerpower.com/rss/steam) на наличие новых бесплатных раздач Steam и рассылает их в подписанные Discord-каналы.

*   **Умная дедупликация**: Уже разосланные игры сохраняются в базе данных — повторных уведомлений не будет.
*   **Фильтрация**: DLC и несегодняшние раздачи автоматически отсеиваются.
*   **Ручная проверка**: Администраторы могут вызвать проверку в любой момент командой `?steam`.

### 2. 📢 Подписки на рассылки
Любой Discord-сервер может подписаться на получение ежедневных уведомлений о Steam-раздачах. Подписки хранятся в PostgreSQL и сохраняются между перезапусками бота.

### 3. 🖼 Распознавание ников со скриншотов
Бот принимает скриншоты из игры в привязанном канале и с помощью **AI (Gemini)** автоматически извлекает игровые ники.

*   **Автоматическая проверка**: Распознанные ники проверяются в базе данных — найденные показываются с описанием.
*   **Быстрое добавление**: Отправка скриншота с текстом `?` добавляет все новые ники в базу.
*   **Индикатор обработки**: Пока бот обрабатывает скриншот, в чате отображается «печатает...».

### 4. 📝 Управление игровыми никами
Администраторы могут вручную добавлять и проверять ники в базе данных через команды бота.

## 🛠 Команды бота

> Команды запускаются с префиксом `?`.

### 👤 Общие команды
| Команда | Описание |
| :--- | :--- |
| `?ping` | Проверить задержку подключения бота |
| `?help` | Показать список всех доступных команд |

### 🛡 Команды Администратора
| Команда | Описание |
| :--- | :--- |
| `?steam` | Немедленно проверить и показать актуальные бесплатные раздачи Steam |
| `?set_steam` | Привязать **текущий канал** к рассылке ежедневных Steam-уведомлений |

> **Примечание**: Эти команды доступны только на серверах участникам с правами администратора или пользователям, перечисленным в `ALLOWED_USERS`.

### 📝 Команды для работы с игровыми никами
| Команда | Описание |
| :--- | :--- |
| `?nick <ники>` | Добавить один или несколько игровых ников в БД (через пробел) |
| `?lol <ник>` | Проверить наличие ника в базе данных |
| `?nicklist` | Показать общее количество ников в базе данных |
| `?nickdesc <ник> <описание>` | Добавить ник с описанием или обновить описание существующего ника |
| `?nickdel <ник>` | Удалить ник из базы данных |

> **Примечание**: Команды работы с никами доступны всем участникам сервера; права администратора в текущем коде не требуются. В личных сообщениях эти команды недоступны.

### 🖼 Обработка скриншотов (в привязанном канале)
| Действие | Описание |
| :--- | :--- |
| Отправить картинку | Распознать ники и проверить их в БД |
| Отправить картинку с текстом `?` | Распознать ники и **добавить** новые в БД |

## 🏗 Технологический стек

*   **Ядро**: `Python 3.13+` & `discord.py` (Cogs architecture)
*   **AI**: `Gemini` через OpenAI-совместимый API — распознавание текста со скриншотов
*   **База данных**: `PostgreSQL` (SQLAlchemy + asyncpg) — хранение подписок, истории раздач и игровых ников
*   **Планировщик**: `APScheduler` (AsyncIOScheduler) — ежедневные задачи по расписанию (МСК)
*   **HTTP**: `aiohttp` — асинхронные запросы к RSS-лентам
*   **Инфраструктура**: `Docker`, `uv` (пакетный менеджер), `Ruff` (линтинг)

## 📥 Полное руководство по установке

### Шаг 1: Скачивание и подготовка

1.  Убедитесь, что у вас установлены [Docker](https://www.docker.com/) и [Git](https://git-scm.com/).
2.  Склонируйте репозиторий:
    ```bash
    git clone https://github.com/ATAGAEV95/Nexus_BotAI.git
    cd Nexus_BotAI
    ```
3.  Создайте файл конфигурации из шаблона:
    ```bash
    cp .env.example .env
    ```

### Шаг 2: Настройка конфигурации (.env)

Откройте файл `.env` и заполните переменные:

| Переменная | Описание |
| :--- | :--- |
| `DC_TOKEN` | Токен бота из [Discord Developer Portal](https://discord.com/developers/applications) |
| `ALLOWED_USERS` | Имена пользователей Discord через запятую, не отображаемые имена и не ID. Даёт дополнительный доступ к `?steam` и `?set_steam`; при пустом значении эти команды доступны только администраторам сервера |
| `DATABASE_URL` | URL подключения к PostgreSQL (формат: `postgresql+asyncpg://user:pass@host:port/db`) |
| `DATABASE_SCHEMA` | Схема PostgreSQL; если переменная отсутствует или пуста, используется `public` |
| `AI_TOKEN` | API-ключ AI-провайдера для распознавания скриншотов |
| `AI_PROVIDER_URL` | Базовый URL OpenAI-совместимого API выбранного AI-провайдера |
| `SCREENSHOT_CHANNEL_ID` | Числовой ID Discord-канала для приёма скриншотов; значение `0` отключает обработку скриншотов |

> **Примечание**: В текущей версии AI-клиент загружается при старте бота, поэтому `AI_TOKEN` нужен даже при `SCREENSHOT_CHANNEL_ID=0`.

### Шаг 3: Сборка и запуск

#### 🐳 Через Docker (рекомендуется)

1.  **Сборка образа**:
    ```bash
    docker build -t nexus-bot-ai .
    ```
2.  **Запуск контейнера**:
    ```bash
    docker run -d --restart=always --name nexus-bot-ai --env-file .env nexus-bot-ai
    ```
